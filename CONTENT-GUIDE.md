# Нарвская Венеция — обновлённый сайт

Откройте index.html. Сайт работает как набор статических файлов, без сборки и установки пакетов. Можно размещать на текущем хостинге. Домен сохранён: kulgunarva.ee.

## Что сделано

Новая главная, общий стиль всех страниц, мобильное меню, русский/эстонский/английский интерфейс, раздел мероприятий, шаблон страницы мероприятия, галерея из 185 фотографий с крупным просмотром и клавиатурной навигацией. Новые фотографии-превью локальные и облегчённые. Оригиналы сохранены.

Существующие формы и подключение доски объявлений сохранены. Их внешние получатели не менялись. При проверке формы не отправлялись. На странице контактов сохранена исходная информация; перед публикацией стоит проверить актуальность расписаний и данных рыболовного клуба.

Карта, платные экскурсии, бронирование и регистрация НКО пока не добавлены. Сайт не утверждает, что НКО уже зарегистрирована.

## Добавление мероприятия

Редактируется events-data.js. Панели администратора пока нет. Фотографии добавляйте в img/events/имя-события/. В массив window.NV_EVENTS добавьте объект:

```js
{
  id: 'postoyannoe-imya-sobytiya',
  date: '2026-09-01', // замените реальной датой
  title: {ru: 'Название', et: 'Pealkiri', en: 'Title'},
  summary: {ru: 'Короткое описание', et: 'Lühikirjeldus', en: 'Short description'},
  body: {ru: 'Первый абзац.\n\nВторой абзац.', et: 'Tekst.', en: 'Text.'},
  location: {ru: 'Место проведения', et: 'Toimumiskoht', en: 'Venue'},
  organiser: {ru: 'Настоящий организатор', et: 'Korraldaja', en: 'Organiser'},
  cover: 'img/events/имя-события/cover.jpg',
  photos: [
    {src: 'img/events/имя-события/01.jpg', alt: {ru: 'Что изображено'}, caption: {ru: 'Подпись и автор фото'}}
  ]
}
```

ВАЖНО: используйте латинские имена папок и файлов, например img/events/summer-meeting/01.jpg (поддерживаются буквы a-z, цифры, дефис и подчёркивание). Пример выше показывает назначение полей, а не опубликованное мероприятие. В поставке архив пуст.

Прямая ссылка: https://kulgunarva.ee/event.html?id=postoyannoe-imya-sobytiya
Не меняйте id после печати QR. Фотографии и текст можно менять. Для нескольких событий отделяйте объекты запятыми. Архив сам отсортируется по дате и покажет выбор года. Если перевода пока нет, используется русский текст.

## Будущие объекты и карта

Объекты должны иметь отдельные постоянные адреса, например /o/01, и собственные карточки: название, автор, описание, координаты, фотографии, связанные события. Реальную карту следует строить по собранным координатам. На компьютере — превью по наведению/фокусу; на телефоне — по касанию. QR ведёт сразу к объекту, а не на главную.
