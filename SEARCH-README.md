# Поисковая оптимизация kulgunarva.ee

Настроены уникальные title и description, canonical на HTTPS-адреса, Open Graph для публикаций ссылок и разметка WebSite/WebPage, ContactPage, CollectionPage и BreadcrumbList. Названия и описания переключаются вместе с языком сайта. Русский текст доступен в исходном HTML.

Sitemap включает главную, галерею, доску объявлений и контакты. Формы add-listing.html и report.html имеют noindex, follow и не включены в sitemap. Robots.txt не блокирует их сканирование: робот должен прочитать noindex. Это не защита доступа.

Главная: «Кулгу Нарва», «лодочные гаражи Нарва», «сообщество Кулгу». Галерея: «фотографии Кулгу». Объявления: «объявления Кулгу», «лодки аренда Нарва». Контакты: «контакты Кулгу». Это темы страниц, а не подтверждённые показатели частотности запросов или обещание позиций.

Первые 30 существующих фотографий галереи теперь есть в HTML до запуска JavaScript. Файлы фотографий не изменялись. Остальная галерея и объявления по-прежнему зависят от JavaScript и внешних источников. У отдельных объявлений пока нет постоянных собственных URL, поэтому их самостоятельная индексация не обеспечена.

Существующий переключатель языка работает на одном URL. Поисковик может преимущественно индексировать русскую версию. Для независимого продвижения эстонского и английского контента понадобится отдельный этап: статические /et/ и /en/ страницы с hreflang. Несуществующие языковые URL не добавлялись.

После загрузки файлов на хостинг:
1. Проверьте https://kulgunarva.ee/robots.txt и https://kulgunarva.ee/sitemap.xml.
2. В Google Search Console подтвердите владение kulgunarva.ee и отправьте sitemap.xml.
3. Добавьте сайт в Bing Webmaster Tools и отправьте тот же sitemap.
4. Проверьте главную страницу инструментом проверки URL и наблюдайте за отчётами индексирования.

Публикация и регистрация в поисковых кабинетах не выполнялись. Рост позиций и срок индексирования не гарантируются. Данные о контактах, должностях и расписании сохранены из исходного сайта и требуют проверки владельцем при изменениях.

Документация Google: https://developers.google.com/search/docs/specialty/international/managing-multi-regional-sites
